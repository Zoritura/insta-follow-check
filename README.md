# Instagram Checker

A simple utility for comparing two Instagram data exports and sorting accounts into a few easy categories.

## What it does

- Reads the exported follower JSON file
- Reads the exported following JSON file
- Compares them and groups accounts into:
  - mutual followers
  - people you follow but who do not follow you back
  - people who follow you but whom you do not follow
- Shows the results in a simple browser page

## How to use

1. Export your Instagram data from Instagram.
2. Put the downloaded JSON files in the same folder as the page.
3. Open the HTML file in a browser.
4. Upload the two files and compare them.

## Notes

This tool works entirely on the local machine. It does not send your data anywhere.
